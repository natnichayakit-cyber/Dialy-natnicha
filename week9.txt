หัวข้อที่เรียน : แก้โจทย์ในใบงานเรื่อง หน้าที่ของ git
สิ่งที่ได้เรียน : ได้เรียนรู้ git ที่ยังไม่เคยเห็นในโจทย์ เช่น git --version

สิ่งที่สงสัย : ถ้าเวอร์ชั่นกิตไม่ตรงกับเวอร์ชั่นกิตของเพื่อน(git เพื่อนเป็นเวอร์ชั่นเก่า) เราควรลบกิตของเราแล้วโหลดกิตที่เวอร์ชั่นตรงกับของเพื่อนไหม หรือให้เพื่อนลบกิตของเพื่อน แล้วให้เพื่อนโหลดกิตใหม่ย่าล่าสุด
